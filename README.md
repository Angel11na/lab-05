
# M1 — відеопам'ять 

Введено константи для розмірів та адреси:
```cpp
const U16 VRAM_LO = 0x0A00;
const int VRAM_ROWS = 32;
const int VRAM_COLS = 64;
```

Функції роботи з віртуальним дисплеєм винесено в окремий простір імен: `namespace display`

### Малювання рамки:

Всередині `main()` перед запуском `ember` для тесту написано:

```cpp
//  --------------  TEST AREA   ----------------------------------------

    //  верхня частина рамки
    for(int i = 0; i < display::VRAM_COLS; i++)
        display::plot(mem, i, 0);
    //  нижня
    for(int i = 0; i < display::VRAM_COLS; i++)
        display::plot(mem, i, display::VRAM_ROWS-1);
    //  ліва
    for(int i = 0; i < display::VRAM_ROWS; i++)
        display::plot(mem, 0, i);
    //  права
    for(int i = 0; i < display::VRAM_ROWS; i++)
        display::plot(mem, display::VRAM_COLS-1, i);

    display::show(mem);

    //  перевірка очищення
    display::clear(mem);
    cout << "\n\n";
    display::show(mem);

    //  ---------------------------------------------------------------------
```

# M5 — пошук по ділянці

Внесено зміни у логіку роботи `find()`:
- команда має семантику: `find <lo> <hi> <byte> <?deepth=8>`
- додано опціональне значення `deepth` - глибина пошуку, за замовчуванням 8
- у сигнатуру функції додано флаг для пошуку ненульового елементу: `void cmd_find(Memory& mem, istringstream &words, bool first_only = false)`
- для пошуку ненульового елементу, потрібно подати `-1` як байт пошуку: `find 0x00 0x08 -1`
- введено пошук лише першого збігу, розділенням команд на `find` та `find_first`:
```cpp
else if (cmd == "find") {
    cmd_find(mem, words);
}
else if (cmd == "find_first") {
    cmd_find(mem, words, true);
}
```
